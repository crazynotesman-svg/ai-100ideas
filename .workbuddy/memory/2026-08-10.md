## 踩坑记录（重要）

1. **本机 workerd 崩溃**：`wrangler types` 和 `astro build` 的预渲染都会触发
   `structured exception #0xc0000005: access violation`（沙箱内外均复现，属本机 MSVC Redistributable 问题）。
   - 解法：`cloudflare({ prerenderEnvironment: 'node' })` 绕过 workerd 预渲染；
     `worker-configuration.d.ts` 手写（`/// <reference types="@cloudflare/workers-types" />` + `Cloudflare.Env`）。
   - 修好 VC++ 运行库后可移除这两处 workaround。
2. **@astrojs/cloudflare v13+ 已移除 `Astro.locals.runtime`**，绑定改为 `import { env } from 'cloudflare:workers'`。
3. `build.format: 'file'` 会让 `Astro.url.pathname` 变成 `/index.html`，canonical/og:url 必须做路径归一化，
   才能和 sitemap 的 `<loc>` 完全一致。

## Phase 3 — 前端 UI + SEO 动态路由

- `src/lib/format.ts`（slugify/formatStars/categoryLabel）、`src/lib/markdown.ts`（parseDescription 拆 Pros/Cons + renderMarkdown，用 marked）、`src/db/queries.ts`（各查询函数）。
- 数据来源：Phase 2 已把 `pros/cons` 以 `## Pros`/`## Cons` 段落写入 `description_md`，所以工具页 Pros/Cons 区块**无需改 schema/迁移**，前端解析即可。

关键决策与踩坑：
- **移除 `@astrojs/sitemap` 集成**，改自建 `src/pages/sitemap.xml.ts`（SSR，查询 D1 动态生成完整 sitemap，含工具/分类/替代页）。原因：静态集成无法收录 `prerender=false` 的动态路由。BaseLayout 的 sitemap 链接与 `public/robots.txt` 均改为 `/sitemap.xml`。
- **Astro 作用域 `<style>` 里的 `theme(colors.slate.700)` 构建失败**（Tailwind v4 在该上下文解析不了），已全部换成字面色值 hex。
- `marked` 作为依赖加入 `package.json`（纯 JS，可上 Cloudflare Worker）。
- `.ts` 端点文件（sitemap.xml.ts）**不能写 `---` frontmatter**，直接 `export const GET: APIRoute`。
